# MIKA ZS LAUCHER

Android Minecraft launcher UI foundation.

## Build APK on GitHub (phone only)

1. Upload ALL files in this folder to the ROOT of your GitHub repository.
2. Make sure this exact file exists at `.github/workflows/build-apk.yml`.
3. Commit to `main` (or `master`).
4. Open **Actions** → **Build MIKA ZS LAUCHER APK**.
5. Open the successful run → **Artifacts** → `MIKA-ZS-LAUCHER-APK`.

Important: do NOT upload this project as a ZIP and expect GitHub to detect the workflow inside the ZIP. The `.github` folder must be at the repository root.
